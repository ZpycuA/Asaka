## 1. HUD 分区

| 区域 | 内容 | 定位 |

| 顶部左 | 任务面板 | `left:12 top:12` |
| 顶部右 | 小地图 | `right:12 top:64`，150×150 |
| 右上偏左 | 击杀提示 | `right:176 top:64` |
| 底部左 | 玩家状态/护甲/负重 | `left:12 bottom:12` |
| 底部右 | 武器/弹药/携带价值 | `right:16 bottom:16` |
| 底部中 | 武器栏 | `left:50% bottom:88` |

### 原则

- 中央准星/命中提示永不被面板覆盖。
- 左下玩家面板、右下武器面板是“永久信息”，不随训练场变化。
- 训练场额外面板不能覆盖左下/右下：现在改为**右侧竖列**，并隐藏训练场的附近物品列表。

## 1.1 战术状态与效果条

- `#tactical-state`：底部中上，显示 `蹲伏 / 疾跑 / 开镜 / 屏息 / 左倾 / 右倾 / 投掷蓄力 / 无人机操控`。
- 侧身同时会通过相机 roll 和该状态条反馈，解决“按了 Z/X 看不出是否生效”。
- `#status-bar` 的效果图标透明度按 `duration / maxDuration` 衰减；`persistent`（技能持续刷新）效果保持不透明。
- `#hazard-overlay`：玩家身上着火/急性玻纤时的屏幕遮罩；`#dazzle-overlay`：强光刺眼时的手部遮眼 + “无法开镜”。
- 死亡时 HUD 健康条强制为 0，状态文字优先显示“死亡 / 濒死击倒”。
- 技能持续期间的斜向流动条纹已移除，只保留边缘氛围光 `fx-skill`。
- 战局内物品详情新增“丢弃到地面”；丢弃生成可再次搜刮的地面物品。
- 背包角色预览左下新增**全身状态面板**：列出所有状态的 `Lv`、剩余时间、着火部位；点击状态可展开简单描述；下方逐部位显示生命%、骨折等级、伤口等级与燃烧等级。

## 2. 训练场 HUD 排版（2026-11-20 修改）

训练场会给 `#hud` 加 `training-mode` 类。

```css
#hud.training-mode #training-settings-btn{ right:12px; top:224px }
#hud.training-mode #training-attack-panel{ right:12px; top:256px; width:248px }
#hud.training-mode #dummy-info-panel{ right:12px; top:382px; width:248px; max-height:34vh }
#hud.training-mode #nearby-list{ display:none }
```

原因：
- 旧版攻击面板/详情面板在左侧 `top:178/392`，与左侧防护按钮、技能按钮、移动端操作键重叠。
- 小地图占右上 `64~214px`，所以训练面板从 `224px` 开始向下排。
- 面板 z-index 提升到 47/48，避免被移动端按钮盖住文字。

移动端（`max-width:900px`）：

```css
#hud.training-mode #training-settings-btn{ right:8px; top:176px }
#hud.training-mode #training-attack-panel{ right:8px; top:208px; width:200px }
#hud.training-mode #dummy-info-panel{ right:8px; top:318px; width:200px; max-height:26vh }
```

> 改训练 HUD 时，先检查 360×640、720×1280、1920×1080 三种尺寸：面板不能覆盖准星、底部玩家/武器面板、右侧主操作键。

## 3. 开火模式按钮

- 位置：`#bottom-right .weapon-box .wb-top #fire-mode-btn`。
- 旧逻辑：只有 `fireModes.length > 1` 才显示 → 单模式枪看不到默认模式。
- 新逻辑：所有非空手/非近战枪都显示；单模式按钮只显示默认模式，不可切换。
- 点击：`_cycleFireMode()` 轮换 `fireModes`；单模式无变化。
- 文案：`_fireModeLabel()`：`single=单发`、`semi=半自动`、`auto=全自动`、`pump=泵动`。

## 4. 投掷轮盘

### 4.1 交互

- PC：按 `T` 打开；保持 Pointer Lock；鼠标位移推动虚拟摇杆；松开/点击确认。
- 触屏：点“投掷轮盘”按钮；在任意位置按下、拖向扇区、松手确认。
- 中心圆：取消。
- 数字键 1~9：快速选择对应扇区。
- `Esc` / `T`：关闭。

### 4.2 布局

- 中心圆 108×108。
- 4 个物品：上/右/下/左。
- 3 个：均分 120°。
- 5~8 个：环形均分。
- 扇区是可点击的大卡片，不是细线按钮；中心有当前选中名称/“取消”。
- 轮盘灵敏度由 `input.wheelSensitivity` 控制，默认 2.4（0.8~4.0 可调）。

### 4.3 投掷手感与保险

- 长按攻击键只负责瞄准/蓄力，**不会自动拔销**。
- 保险式投掷物必须点击 HUD 的「解除保险」按钮或按 `J`，引信才开始倒计时；玩家可以边转向瞄准边主动解除。
- 解除后按钮显示剩余引信；手里到点会自爆。
- 压感式没有引信，撞墙/地面/人立即引爆。
- 投掷力度由 `input.throwPower` 控制；基础速度 24→38m/s（随蓄力）。

### 4.3 为什么改

- 旧版是纵向列表，按钮小、指针锁定切换导致闪屏/点空。
- 新版保持 Pointer Lock，不反复 `exitPointerLock/requestPointerLock`；用 `pointerdown/up` + `mousedown/up` 兜底。
- 轮盘打开时 `_updatePlayer` 冻结玩家输入，避免点击轮盘误开火。

### 4.4 医疗轮盘

- PC `N` / HUD「医疗轮盘」按钮；与投掷轮盘共用径向 UI，数据源是 `_getMedicalWheelList()`。
- **医疗轮盘与投掷轮盘完全同构**：保持 Pointer Lock，用鼠标位移/拖拽推动扇区，松手/点击确认；不再强制退出鼠标锁定。
- 数据源递归扫描胸挂/背包/口袋/安全箱及其 `innerGrid`，药放在背包内部网格也能识别。
- document 捕获层记录按下时的 `.nw-slot`，即使手指滑出卡片，pointerup 仍按按下卡片结算。
- 数字键 1~9、方向键（上/下/左/右）+ `Enter`/空格均可选择；医疗模式不会再误走投掷物。
- 已在投掷轮盘时按医疗键会直接切换到医疗轮盘（反过来同理），不会只关闭。

### 4.5 队内战术对话

- 匹配友方 AI 后，`#squad-chat` 在**桌面顶部中央 / 移动端小地图下方右侧**显示纯文字战术字幕；没有背景框/边框，只有文字和阴影。
- 最多 4 行、单行省略、`pointer-events:none`，不会在移动/转身时误触滚动；历史仍保留在 `_squadChat`，`destroy()` 清空避免下一局残留。
- 内容：发现敌人、交战计划、换弹/低血量、玩家重伤/倒地、标记共享、医疗兵包扎、救起队友、队友投掷手雷。

### 4.6 队内建议与救治

- `P` 前进建议、`O` 撤退建议：以准星落点生成 3D 标记环 + 光柱，持续 8s；HUD 左下也有两个按钮，只在有存活队友时显示。
- 无人机操控中同样可按 `P/O`，标记点取**无人机当前准星**的鸟瞰落点，不再被无人机分支提前 `return` 吞掉；无人机 HUD 也提供「前进点 P / 撤退点 O」按钮给移动端。
- 建议只是建议：队友按自身血量/视线判断；撤退建议在血量 <80% 或没有视线时更可能被采纳。
- 靠近队友 4.5m 内默认只显示一行 `#ally-care`：名字 · 状态 · 血量 · 按 U 查看；按 `U` 才展开部位/伤口/状态/药品按钮。
- 面板默认透明背景、无边框，位于任务面板下方；移动端仍在左下；无人机操控中隐藏。
- PC 按 `U` 释放鼠标（关闭时恢复），点击面板里的药品按钮；手术包/血浆可以把倒地队友救起。移动端直接点按钮。
- 面板用 `onclick + world` 标记覆盖绑定，换局不会误调上一局 world。
- 小地图绘制队友位置：存活绿点、倒地红点 + 白叉。
- 死亡回放期间 `#hud.replay-hud` 会隐藏队内聊天/建议按钮/队友面板；`_startReplay` 清空 3D 建议标记并禁止 P/O，回放结束再恢复。
- 外骨骼 `#exo-panel` 在屏幕上方显示电量/头显/自动火力；`#exo-overlay` 为全屏 NIPsel 接入选单。`L` 切目镜，`I` 切自动火力。
- 激光改为毫米级细束 + 小落点光点；战术灯只保留真实 SpotLight，不再有可见的 10m 圆锥。两者都消耗配件内置电池，EMP 损坏后隐藏；无人机操控中不显示玩家枪模/激光/灯。
- 动作进度条（`#action-progress`）上的「取消 (⌫)」与 Backspace 走同一个 `_cancelCurrentAction()`；按钮监听按 `GameWorld` 重绑，换局后不会指向已销毁的旧世界。
- `I`：无外骨骼头显时检视当前武器（2.4s 抬枪翻转）；有外骨骼时 `I` 仍是自动火力。
- 2 倍/4 倍镜开镜时枪模与镜筒移到屏幕中心，不再使用全屏黑色蒙版；镜片半透明。
- 榴弹炮详情显示 4 个弹膛格（左→右为发射顺序）；战局内点“装 1”逐发压入任意投掷物，设为首选后按 R 优先装该弹种。
- Pointer Lock 下按 `Alt` 释放鼠标，可点击战术灯、外骨骼自动火力等 HUD 按钮；再按 `Alt` 锁回。`nearby-list` 移到左上，点击打开搜刮。

## 5. 靶场设置面板

### 5.1 选项

- 显示伤害数字
- 显示攻击数据面板
- 无限子弹
- 无限投掷物
- 启用技能
- 技能无冷却
- 人偶移动：`静止 / 左右巡逻 / 随机游走`
- 人偶血量：50/100/200/500
- 人偶护具：头盔壳 / 面罩 / 纤维内衬 / 防弹插板，各自独立下拉
- 创造模式 + 打开物品库
- 补满配装 / 重开靶场 / 应用 / 关闭

### 5.2 应用逻辑

`_applyTrainingModal()`：

- 读取所有控件。
- `dummyMoveMode`：`still/patrol/random`。
- `dummyGear`：四个槽位的 defId 或 null。
- `_applyTrainingSettings()`：
  - 对所有人偶调用 `_reviveTrainingDummy()` / `_configureTrainingDummy()`，清空上次状态并复位。
  - 重置血量/血液/伤口，扶正倒地人偶。
  - 按 gear 重建 `enemy.armor`（等级、耐久、`defId`、`red`）。
  - 补满玩家配装。

### 5.3 人偶移动与复位

- 死亡人偶不生成搜刮箱/尸体箱，模型倒地保留，避免遮挡靶场。
- 只有“应用设置 / 重开靶场”会把死亡人偶复位，并清空上一次的所有状态、伤口、着火部位与护甲耐久。
- 复位还会重置 `state/stateT/isCrouching/hitFlash/fireCd/burst/currentSlot/weapon/倒地姿态/painkillerDoses/mesh.rotation/scale` 与随机移动目标；不会带着上一轮战斗状态复活。
- 正常战斗不会自动复活人偶。

`AISystem._trainingDummyMove()`：

- `still`：不调用，停住。
- `patrol`：以出生点为中心，左右 ±4m，2.2m/s。
- `random`：在出生点 ±6m（x）/±1.5m（z）随机目标，1.8m/s，2~4.5s 重选。
- 始终面向玩家，方便查看详情/测试护具。
- 直接更新 `body.position`，并清零速度，避免物理积分冲突。

## 6. 人偶详情面板

显示条件：训练场 + 玩家 6.5m 内最近的一只存活训练人偶。

内容：
- 名称、距离
- 当前 `getHealthText()`、健康度 %
- 血液 ml / max
- 异常状态（图标 + 名称 + 强度）
- 四件护具：名称 + 耐久 %

更新：
- `HUDSystem._updateDummyInfoPanel(w)`，每帧计算最近人偶，做签名比较，只在内容变化时重绘。
- 应用靶场设置时 `_configureTrainingDummy()` 会从固定 `PART_MAX_HP` 重建基准、清伤口/状态/血液，并清空 `_dummyInfoSig` 强制重绘，避免仍显示上一轮伤口。
- `#hud.replay-hud #dummy-info-panel{display:none}`，回放不显示。
- `_clearMatchUI()` 退出时隐藏。

## 7. 创造模式物品库

- 入口：靶场设置 → 勾选创造模式 → 打开物品库。
- 打开前会先应用靶场设置（避免护具/移动改了没生效）。
- 分类按钮直接发放：
  - 武器装满弹匣
  - 弹药 120 发
  - 投掷物 3 枚
  - 防具/背包/胸挂按原物品创建
- 放入顺序：`bag → chest → pocket → stash`；全部失败则销毁并提示。
- 只对训练场生效，不写入正式玩法。

## 8. 死亡回放

### 8.1 快照

- 10Hz，保留最近约 15s。
- 每帧记录玩家/所有敌人：位置、朝向、生死、击倒、HP、血液、护具、武器名、弹匣、备弹、瞄准点、`status.effects`。
- 另记录射击事件（敌方开火/是否命中玩家）与瞬时表现事件（爆炸、闪光球、技能光环）。

### 8.2 回放开始

- 清空 `fx-filter` 暗红蒙版、`fx-vignette`、`fx-hit-flash`、`fx-coupling`、`fx-skill`、`blind-overlay`、`flash-overlay`、眼皮、无人机干扰。
- 退出 Pointer Lock，隐藏移动端控件/暂停按钮。
- 隐藏玩家第一人称枪模，构建击杀者第一人称枪模。
- `hud.replay-hud`：保留玩家同款 HUD，隐藏任务/小地图/击杀提示/附近列表/武器栏/技能栏/防护/训练面板/血雾滤镜/伤害指示器。

### 8.3 回放每帧

- 插值实体位置/朝向。
- 状态效果：身体发光（致盲白、震撼紫、燃烧橙、流血红）+ 头顶状态图标。
- 击杀者 HUD：HP、护具、武器、弹匣、状态栏、受击红闪。
- 击杀者失明：显示 `blind-overlay`。
- 无击杀者：HUD 显示“死亡回放 / 无击杀者”，不残留玩家濒死面板。
- 爆炸/闪光/技能光环按事件时间轴重放。

### 8.4 回放结束

- 清空状态图标/材质发光。
- 恢复玩家武器可见性、击杀者身体可见性。
- 移除 `replay-overlay`、`replay-hud`。
- 回到战斗记录/结算页。

## 9. 键位与移动端布局

### PC

保持主流 FPS：
- WASD 移动，Shift 疾跑，Space 跳，C 蹲。
- 左键开火，右键开镜，R 换弹，F 切枪。
- 1/2/3/0 武器槽，Q/E 技能，G 投掷，T 轮盘，B 背包。
- `[ ] \` 防护，Y 无人机，Z/X 倾斜，H 屏息，K 拔除/灭火，`M` 尾击（Prazer），Esc 暂停。

### 移动端（2026-11-20 调整）

右侧主战斗区：
- 开火：右下，`right:20 bottom:100`，76px。
- 开镜：开火上方，`right:20 bottom:188`，55px。
- 换弹：开火左侧，`right:102 bottom:112`，58px。
- 蹲：右下偏左，`right:112 bottom:38`，55px。
- 跳：右下更左，`right:196 bottom:38`，60px。
- 尾击：跳跃上方，`right:196 bottom:100`，54px（Prazer）。
- 救治：`right:196 bottom:160`，54px；外骨骼目镜：`right:196 bottom:218`，54px（仅外骨骼激活时显示）。
- 切枪：右上，`right:20 bottom:268`，55px。
- 背包：切枪左侧，`right:82 bottom:268`，55px。

左侧：
- 技能、投掷轮盘、无人机、倾斜、屏息。

> 原则：开火/开镜/换弹/蹲/跳形成右手拇指可覆盖的扇区；切枪/背包上移；技能/投掷在左手。不要把开火键放在屏幕中央或与换弹重叠。
