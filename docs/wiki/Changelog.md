## 2026-11-20 · 弹链/弹药详情 + 靶场 UI + 伤害校准 + Wiki

### 1. 弹药与弹链

**旧行为**
- 武器详情只显示 `loaded.ammoType` 和 `qty`；混合弹链只显示一个弹种，数量是假的。
- 详情“装填/扣下”按容器顺序抓弹，无法指定弹种。
- 靶场无限子弹在 `_fireWeapon` / `_finishReload` 里用默认弹种覆盖整条弹链，玩家排好的特殊弹会消失。
- `reserve` 只统计默认弹种；有玻璃纤维弹但显示 0，导致无法换弹。
- 扣弹按弹种汇总后清空 queue，可能与实际剩余不一致。

**新行为**
- `inventory.js` 新增弹链 API：`normalizeLoaded / getLoadedGroups / isAmmoCompatible / listCompatibleAmmo / loadAmmoFromItem / unloadAmmo / countCompatibleAmmo / consumeCompatibleAmmo`。
- `loaded.queue` 是唯一真相源；`qty` 只做缓存；`loadedPreference` 记录首选弹种。
- `bagUI` 详情显示真实弹链分组（按顺序）、下一发、首选弹种；支持 `装 1 / 装满 / 取 1 / 全取 / 全部扣下`。
- 正常战局内改为“设为首选 + R 换弹”；靶场/仓库可直接整理弹链。
- 靶场无限弹药只补足队列，不覆盖已有顺序；优先补 `loadedPreference`。
- `reserve` 按兼容口径统计随身容器（不含仓库）。
- 旧存档 V1/V2 反序列化、`createItem`、`transferItem` 都调用 `normalizeLoaded` 修复弹链。

**文件**
- `inventory.js`
- `bagUI.js`
- `game.js`

**验证**
- 混合弹链显示顺序正确；取 1 不改变其余顺序。
- 5.56 武器装玻璃纤维弹后 `reserve` 非 0，换弹优先装它。
- 靶场射击后已排好的弹链顺序不被整体覆盖；特殊弹会按队列顺序逐发消耗，补弹从队尾加入。
- 背包满时扣弹整体回滚，不丢子弹。

### 2. 伤害/健康模型校准

**旧行为**
- 护具吸收硬编码等级表，与 `content.armor.red` 不一致。
- 头部壳+面罩双层叠加；腹部也吃插板。
- 未击穿统一 `remaining *= 0.25` 钝击。
- 护具耐久 `absorbed / 25`。
- 即时失血固定 `energy * 0.4`；低血容量 50% 才触发。
- 健康度只看组织，不看失血。

**新行为**
- 护具吸收以 `content.armor.red` 为单一来源。
- 分层钝击：插板 0.08、头盔壳 0.10、面罩 0.12、纤维 0.28；只有未击穿才乘。
- 头部只走一层；胸部先插板后纤维；腹部只走纤维。
- 耐久按 `absorbed / 40J` 消耗。
- 即时失血 = `energy * 0.08 * 部位血管密度 + 伤口等级 * 12`。
- 低血容量阈值 35%。
- `healthQuality = min(组织健康, 血液比例)`。
- `CombatSystem.applyArmor` 删除隐藏的全局 ×0.25。

**文件**
- `game.js`

**验证**
- Lv3 插板吃 5.56 不致命，护具耐久按 40J/点下降。
- 头部不再双重护具；腹部不吃插板。
- 受伤后 HUD 健康度随失血下降；35% 触发低血容量。

### 3. 靶场

**旧行为**
- 人偶移动只有布尔开关，且默认关闭。
- 人偶护甲只能选统一等级。
- 没有靠近人偶的详情面板。
- 没有创造物品库。

**新行为**
- 三档移动：静止 / 左右巡逻 / 随机游走，默认左右巡逻。
- 四个护具槽独立选择 content 中任意防具。
- 靠近 6.5m 显示详情：状态、健康度、血液、异常状态、护具等级/耐久。
- 创造模式物品库：所有武器/弹药/近战/投掷物/防具/背包/胸挂。
- 应用设置时扶正倒地人偶、重置伤口/血液/护甲。

**文件**
- `game.js`
- `index.html`

**验证**
- 切换移动模式，人偶按模式移动。
- 四槽护具分别选择不同装备，详情显示正确。
- 创造模式发放武器/护具进入背包。

### 4. HUD/键位

**旧行为**
- 开火模式按钮只有多模式枪才显示。
- 训练场攻击面板/详情面板在左侧，被防护/技能/移动端按钮覆盖。
- 移动端开火/换弹/开镜/跳/蹲位置拥挤。

**新行为**
- 所有枪显示开火模式；单模式只展示默认值。
- 训练场面板移到右侧竖列（小地图下方），隐藏训练场附近物品列表，提升 z-index。
- 移动端右侧主战斗区重排：开火/开镜/换弹/蹲/跳形成拇指扇区；切枪/背包上移。

**文件**
- `game.js`
- `index.html`

**验证**
- 单模式枪也能看到“半自动/全自动”等默认模式。
- 训练场面板不再被左侧按钮挡住。
- 移动端按钮不互相重叠、不开镜误触。

## 2026-11-15 · 死亡回放 / 径向轮盘 / 训练场地图保底

### 死亡回放
- 旧：回放带着玩家死亡时的 `fx-filter` 暗红蒙版、眼皮、技能滤镜；敌人致盲等状态看不到。
- 新：
  - `_resetScreenFx()` 统一清全屏效果。
  - 快照记录 `status.effects`；回放给实体加状态图标 + 身体发光。
  - 记录爆炸/闪光/技能光环事件，回放重放。
  - 无击杀者时 HUD 中性显示，不残留濒死面板。
  - `replay-hud` 隐藏 `fx-filter/fx-coupling/fx-skill/dmg-indicator`。
- 文件：`game.js`、`index.html`。

### 投掷轮盘
- 旧：纵向按钮列表，点空/闪屏。
- 新：中心圆 + 四/八向扇区；PC 保持 Pointer Lock；鼠标位移推动虚拟摇杆；触屏拖动/点击；中心取消。
- 文件：`game.js`。

### 训练场地图
- 旧：点击训练场报“地图不存在”。
- 新：
  - `startMatch('training')` 有内置 `mapSpec` 兜底。
  - 地图 JSON 加载失败使用内置靶场布局。
  - 相对路径按 `import.meta.url` 解析。
- 文件：`game.js`。
