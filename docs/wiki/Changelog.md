## 2026-11-21 · 震撼三维判定 / 闪光附带震撼 / 耳鸣听力 / 纤维+插板双耐久 / 医疗记录 / 投掷归类

**旧行为**
- 震撼弹/闪光弹只用水平 `x/z` 距离判定：扔到百米高空，只要水平投影在半径内就会被震到/闪到；墙体只对闪光有部分遮挡。
- 闪光弹只有失明/刺眼，没有震撼效果。
- 被爆炸/震撼命中没有耳鸣、听力下降的反馈，背景音效音量不变。
- 纤维护甲只显示一个耐久百分比，内嵌插板的耐久只能打开详情看。
- 使用医疗物品不会写入战斗记录，也没有统计。
- 战斗记录把 `nade_throw` 归进“技能”筛选组。

**新行为**
- `_applyStun` 与闪光判定改为**三维距离**（含高度）+ 墙体遮挡衰减；高空爆炸不再影响地面目标。
- 闪光弹在近距/高照度时附带震撼：眩晕 0.8~2s 量级，按距离衰减。
- 新增 `tinnitus` / `deafened` 状态：
  - 爆炸/破片按能量施加耳鸣，近距离爆炸额外短时耳聋；
  - `_playSFXAt` 按 `Status.getHearingMul()` 削弱外界声音（耳鸣 ~42%，耳聋 ~20%，震撼 ~70%）；
  - 耳鸣时播放 3.9k/6.1k 高频铃声，1.2s 内不重复叠加。
- 背包格与装备槽对纤维护甲显示两行耐久：下面纤维、上面 `🛡插板`；详情仍只显示百分比。
- 使用医疗物品会写入 `medical_use` 战斗记录，并在战斗报告摘要中统计“医疗使用”。
- 战斗记录筛选新增「投掷」组，`nade_throw` 不再归入技能；`medical_use` 归入「物品」。
- `FILTER_GROUPS.items` 增加 `medical_use`，`skills` 只保留 `skill_use`。

## 2026-11-21 · 医疗轮盘 / 制式券配装页 / 货币显示

**旧行为**
- 医疗物品只能打开背包、找到物品、点详情再使用，战斗中操作链路过长。
- 只有一个“领取制式券”按钮，固定发放角色默认枪械/护甲/弹药，没有档位、随机与刷新。
- 进入战局时自动补发初始装备，玩家无法选择“什么都不带”。
- 菜单没有显示当前 cp（货币）。

**新行为**
- 新增医疗便携轮盘：
  - PC 按 `N`，移动端左侧新增绿色“医疗轮盘”按钮，HUD 右侧出现“🩹 医疗轮盘”入口。
  - 与投掷轮盘共用同一套径向 UI；列出胸挂/口袋/背包/安全箱中所有 `medical` 且带 `use` 的物品。
  - 选中后直接调用 `_useMedical(uid)`，走动作进程与取消逻辑，不需要打开背包。
- 新增“制式券 / 配装”页面（`#loadout-page`）：
  - 四个档位：轻装、标准、重装、特种；每档有独立武器池、护甲等级区间、背包/胸挂、弹药量、医疗/投掷物/配件数量与特殊装备。
  - 每次进入/刷新都会重新随机；高档位有概率双主武器（主 + 副槽两把长枪）和特殊装备。
  - 预览显示武器关键手感数值（口径、弹匣、rpm、射程、后坐、价值）与配装估值。
  - “领取并装备”会清空随身装备与胸挂/口袋/背包后写入新配装；“空装进入”只清空随身装备，保留仓库与安全箱，玩家可自己从仓库配装。
  - 数据来自 `content.loadoutTiers`，新增档位只改数据。
- 进入普通战局不再自动发放初始装备/投掷物；训练场仍自动补测试配装。
- 菜单顶部与配装页显示实时 `cp`；市场购买、背包出售、战局结算后都会刷新。
- `_stripInventoryForLoadout()` 不再清空安全箱，避免配装误删贵重品。

## 2026-11-21 · AI 交战距离 / 程序化音效 / 插板嵌套 / 容器类型 / 投掷物碰撞

**旧行为**
- AI 进入 combat 后只按侵略性无脑贴近，进入射程也不一定停下开枪；远距离感知被固定 18~46m 卡死。
- 游戏几乎静默：只有少量合成音效，没有脚步/搜刮/远距离枪声，也没有距离衰减与左右声像。
- 蹲下仍可疾跑；AI 脚步声不进声纹。
- 背包只有一条 3px 耐久条，没有百分比；详情直接给出精确耐久数值。
- 插板可以单独穿在 `vestPlate` 槽，现实中不存在；替换插板时经常因为空间不足失败。
- 双击拿取会先弹出详情、再移走物品，面板闪烁且显示已不存在的物品。
- SR762 使用 7.62×39 中威力弹，与“狙击枪”定位不符。
- 破片/EMP 只影响玩家和敌人，无人机悬停在空中完全免疫爆炸。
- EMP 的“抗磁”等于免疫；无人机图传干扰是绑定在屏幕上的全屏特效，退出操控后仍可能残留。
- 所有容器共用同一个箱子模型，名字都叫“物资容器”，掉落表也是全局随机。
- 定时引信投掷物只判断地面，会直接穿过墙/箱子；落地/撞墙没有声音，AI 也不会躲手雷。
- AI 打无人机 75% 命中、每秒一枪，几秒就能把 70 耐久无人机打爆。

**新行为**
- AI 按武器有效射程与 `keepDistance` 保持交火距离：太远推进、太近后撤、进入射程站定/侧移射击；移动中射击散布增加。
- `_findTarget` 视野距离改为 `max(感知距离, 武器 range × 0.8)`（上限 140m），狙击手/精确射手能更早发现目标。
- 程序化 WebAudio 音效：手枪/步枪/狙击/霰弹枪声、走/跑/蹲脚步、搜刮、爆炸、换弹、切枪、命中、护甲跳弹、空仓、投掷物碰撞。
- `_playSFXAt` 按距离衰减音量并按相机朝向做左右声像；AI 通过 `emitSound` 听到脚步与更远的枪声。
- 蹲姿禁止疾跑；AudioContext 首次交互后自动 `resume`。
- 背包格左下角显示耐久百分比；详情只显示百分比，不显示精确耐久值。
- 插板并入纤维护甲的 `subSlots.plate`：
  - 不能单独穿插板；旧存档 `vestPlate` 槽自动迁移。
  - 拖插板到护甲即装入；被换下的旧插板优先放回新插板腾出的格子，空间不足则撤销替换。
  - 护甲详情可取出插板；搜刮尸体时可单独拿走内嵌插板；跨 Inventory 转移会一起迁移。
- 双击/双触改为 200ms 单击延迟 + 双击判定，快速拿取后关闭详情；搜刮详情新增“拿取”按钮。
- SR762 改为 7.62×54mmR 全威力弹（`762x54`，含 GF 变体）；新增 DMR-54、LMG-556、SMG-9、P-45、R-357 及 `.357` 弹。
- 新增 5 级头盔/面罩/纤维护甲、重型背囊/胸挂、止血带/止血粉/吗啡/肾上腺素/生理盐水、金条/钻石/军功章/笔记本/野战电台/银锭。
- 无人机现在受破片/爆炸伤害；EMP 对无人机按 `empResist` 折算耐久损失。
- “抗磁”统一改称“电磁加固”：只降低 EMP 损坏概率并非免疫；加固物品仍会掉耐久/留下 `empSurge`。
- EMP 警告拆分为“电子物品已损坏”与“强电磁干扰（加固设备被冲刷）”；`emp_silence` 显示名改为“强电磁干扰”。
- 无人机图传干扰改为仅在操控无人机时显示：雪花噪点 + 马赛克 + 扫描线；退出/坠毁/战局结束立即清空。
- 容器类型进 `content.containers`：物资箱/弹药箱/医疗箱/工具箱/保险柜/冷藏柜，各自有模型尺寸、颜色、显示名、物品件数与分类权重。
- 定时引信投掷物加入逐帧线段碰撞：撞墙/箱子按法线反弹，落地/撞墙发出 `nade_bounce` 声并写入声纹。
- AI 检测到 9.5m 内的爆炸投掷物会进入 flee 并向反方向跑，威胁消失后回到战斗。
- AI 打无人机命中率降为约 2%~30%（随距离/感知变化），伤害 4~9，射击间隔 0.95~2.05s，并放大脱靶曳光散布。
- `transferItem`/拆分/掉落现在保留 `damaged`、`empSurge`、`loaded.disabled`，损坏物品不会因为换背包“一秒修好”。

## 2026-11-21 · 倒地穿模 / 压感自爆 / 局部燃烧 / 闪光增强 / 独立保险 / 背包状态

**旧行为**
- 倒地相机下沉 0.8m，眼高又被压到 0.55m，镜头能看到地面以下。
- 压感投掷物仍走 `fuse` 倒计时，出手 0.02s 就在面前爆炸。
- 燃烧每帧随机挑一个部位、按 `42J/s` 结算，可能两秒内连续烧到头；HUD 是全身「燃烧」。
- 闪光衰减过快、阈值过高，几米外只剩强光刺眼甚至无效。
- 保险式投掷物长按攻击键自动拔销，瞄准时引信已经在烧。
- 背包只有部位标签，没有全身状态列表、等级、说明；燃烧等状态看不出部位。
- 龙息弹/玻纤弹命名过短，玻纤只有 5.56 一种口径。
- EMP 空爆或范围内没有电子物品时仍发全图警告。
- 死亡人偶被复位后继承上次状态；死亡还会生成搜刮箱，遮挡靶场。
- 详情页在换弹动作中仍可能重复触发装填/卸下。

**新行为**
- 倒地相机改为小幅下沉 0.12m，眼高 0.55m，镜头保持在地面以上。
- 压感式不再递减时间引信，只在撞墙/地面/人时引爆；8 秒未命中才自毁。
- 燃烧改为 `status.burningParts`：
  - Dragon’s Breath 只点燃命中部位；燃烧瓶从腿部开始。
  - 每部位 `level * 8 J/s`、`level * 1.6 ml/s`，不再随机烧头。
  - 每 4 秒才向相邻部位扩散 1 级；HUD、3D 火焰、背包面板都只显示实际着火部位。
- 闪光弹半径 20m、失明基准 7s；照度阈值 0.35，5m 内基本必盲，10m 左右才转为刺眼。
- 保险式新增独立「解除保险」按钮与 `J` 键；长按攻击键只瞄准，不会自动拔销。
- 背包角色预览新增全身状态面板：所有状态显示 `Lv`/剩余时间，点击展开描述；部位逐项显示生命%、骨折、伤口、燃烧等级。
- 龙息弹显示名改为“12 号龙息燃烧弹（Dragon’s Breath）”；新增 `9mm_gf / 762_gf / 45acp_gf / 12ga_gf`，5.56 的 `glassfiber` 显示为“5.56×45mm GF 玻纤弹”。
- EMP 只有实际干扰到目标/电子设备时才发警告。
- 训练人偶死亡不再生成搜刮箱；复位时清空状态/着火/伤口。
- 装填/卸下在换弹动作进行中被拒绝，避免一个动作完成两项变化。

## 2026-11-21 · 枪伤出血 / 护甲同步 / 详情丢弃 / 回放击杀者修复

**旧行为**
- 中枪瞬间失血系数只有 `0.08`，5.56 胸部约 211ml（4%），看起来像“先只造成伤口再慢慢流血”；持续流血 `24ml/s/级`，高级伤口也慢。
- 武器详情里的“取 1 / 全取 / 装 1 / 装满”在战局内仍可能瞬间改弹链。
- 所有枪械被标成 `electronics`，EMP 会把 AR-556 等机械枪也判损坏。
- 详情页没有战局内“丢弃到地面”按钮；旧丢弃逻辑在战局外直接 `destroyItem`。
- `player.armor` 只在出生时构建一次：脱甲后仍承伤、背包里的甲仍掉耐久、换甲仍消耗旧甲。
- 死亡结算读取 `player._lastDamageSource`，但旧代码只写了 `world._lastDamageSource`，导致死亡回放固定显示“未知”。
- 技能持续期间的斜向流动条纹一直划过屏幕。

**新行为**
- 即时失血改为 `energy * 0.18 * vascularity + woundLevel * 35`；5.56 胸部 1700J ≈507ml，命中瞬间就掉约 10%。
- 持续流血 `40ml/s/级`；4 级伤口约 160ml/s。纤维/燃烧附加失血仍保留。
- 战局内（含靶场）详情隐藏直接装卸按钮，只保留“设为首选”，按 R 走换弹动作；战局外仍可整理。
- 所有基础枪械改为机械/抗磁（`electronics:false, empShielded:true`）；EMP 只损坏耳机、硬盘等非抗磁电子物品。
- 详情新增“丢弃到地面”：支持装备槽、背包/胸挂，内部物品一并掉出，生成可搜刮地面物品。
- `_syncArmorFromInventory()` 在换甲/脱甲/背包关闭/负重刷新时重建 `player.armor`；背包里的甲不再承伤。
- `_damagePlayer` 同时写 `player._lastDamageSource`；死亡回放能显示真实敌人/破片来源；击杀者已死亡也能记录。
- 删除 `fx-skill-lines` DOM/CSS 与斜纹动画。

**文件**
- `game.js`
- `bagUI.js`
- `content.js`
- `inventory.js`
- `index.html`
- `docs/wiki/*`

**验证**
- 5.56 打胸：命中帧血液明显下降，随后持续流血；不做处理会较快死亡。
- 战局内详情没有“装/取”按钮；按 R 才有换弹动作。
- EMP 后 AR-556 仍可开火；耳机/硬盘显示[损坏]。
- 脱掉护甲后受击不再吃甲；换敌人甲后耐久扣在新甲上。
- 详情“丢弃到地面”后附近列表出现该物品，可再次搜刮。
- 被敌人击杀/被手雷炸死时，死亡回放显示对应来源，不再固定“未知”。

## 2026-11-21 · 生死同步 / 投掷与光场 / 负重与战利品 / 状态反馈

### 1. 伤害显示与生死判定

**旧行为**
- 击倒/击杀提示显示的是“最后一发”的伤害，却写着“累计造成”。
- 伤害数值/状态强度可能带多位小数。
- 死亡/击倒只在 `_damageEnemy/_damagePlayer` 的受击瞬间检查；流血、燃烧、玻纤、失血造成的血液归零不会触发死亡，人偶会“血量 0 还站着”。
- 倒地后仍可跳跃、翻背包，身体高度会被恢复为站立，出现“自己站起来”的假活人观感。
- 训练人偶死亡后没有统一状态，设置面板一应用又会复活，观感像“隔几秒自动恢复”。

**新行为**
- `_syncEntityLifecycle()` 每帧对玩家/所有敌人检查 `status.isDead()/isDowned()`，持续伤害也能正确触发击倒/死亡/倒地姿态。
- 敌人累计玩家造成的有效伤害 `_damageFromPlayer`；击倒/击杀提示与战斗记录的 `damageContributed` 使用累计值，并统一 `Math.round`。
- 死亡时把 `blood` 归零并刷新健康度，状态条在死亡帧恰好为 0；`getHealthText()` 先判死亡/击倒。
- 倒地玩家锁定为 0.9m 碰撞高度、禁止跳跃/疾跑/开背包，镜头降到低位；覆柔/主动复位才恢复站立。
- 只有“应用靶场设置/重开靶场”会复活人偶，正常战斗不会自动复活；死亡人偶保持倒地可见。
- 烧伤/流血中的实体每帧同步生死，不再依赖下一发子弹。

**文件**
- `game.js`
- `bagUI.js`
- `content.js`
- `locale.zh-CN.js`

**验证**
- 用龙息弹/玻纤弹打人偶，血液归零的同一帧显示死亡并倒地，不需要补一枪。
- 只靠流血把血液耗尽，玩家/敌人会死亡；HUD 血量条为 0。
- 倒地时按空格/B 无效；覆柔触发后恢复站立。

### 2. 投掷物：轮盘灵敏度、抛掷物理、压感/保险

**旧行为**
- 轮盘鼠标位移 1:1 推动，半径 140px，实际几乎转不动。
- 投掷固定 20m/s + 2.5m/s 上抛，稍远就要把视角抬到天上。
- 所有投掷物都是“选中→直接扔→落地引信”，没有压感式，也没有拔销后手里倒计时。
- 破片固定 3 片；爆炸伤害日志会继承当前武器，看起来像 5.56 打的。

**新行为**
- 新增 `input.wheelSensitivity`（默认 2.4，设置可调 0.8~4.0）与 `input.throwPower`（0.7~1.6）。
- 投掷改用蓄力：长按攻击键蓄力，速度 24→38m/s，上抛 3.0→4.8m/s，重力 14；预览轨迹同步。

### 3. 闪光/EMP 光场与强光失明

**旧行为**
- 闪光只按半径给范围内所有人生成 `blind`，没有距离/视线衰减，也没有真实光源。
- 玩家在半径内几乎必定全白失明；没有“很亮但不致盲”的中间状态，也不禁止开镜。
- EMP 只是眩晕 AI，没有电子物品损坏。

**新行为**
- 新增 `_spawnLightField()`：真实 `PointLight` + 扩散球，亮度随距离衰减。
- `_applyFlash()` 用距离平方衰减 + 墙体射线遮挡计算照度：
  - 照度 ≥0.55 才失明；
  - 0.10~0.55 进入 `dazzle`（强光刺眼），强制退出开镜并显示抬手遮眼遮罩。
- 玩家与 AI 共用该规则；背闪复用同一套光场/衰减逻辑，自身免疫。
- 新增 EMP 电磁场：`_applyEmpField()` 按距离衰减，范围内所有非抗磁电子物品损坏，`[损坏]` 名称、价值 ×0.12、电子枪械无法开火；EMP 同时损坏无人机并发出级别 0 警告“所有非抗磁电子物品已损坏”。
- 新增 `dazzle / emp_disrupted / emp_silence` 效果定义。

**文件**
- `game.js`
- `content.js`
- `index.html`
- `locale.zh-CN.js`

**验证**
- 闪光弹在墙后不生效；近处失明、远处只刺眼且不能开镜。
- EMP 后 AR/SMG/狙击无法开火，耳机失效，硬驱变成[损坏]；AK/P9 仍可用。

## 2026-11-20 · 弹链/弹药详情 + 靶场 UI + 伤害校准 + Wiki

### 1. 弹药与弹链

**旧行为**
- 武器详情只显示 `loaded.ammoType` 和 `qty`；混合弹链只显示一个弹种，数量是假的。
- 详情“装填/扣下”按容器顺序抓弹，无法指定弹种。
- 靶场无限子弹在 `_fireWeapon` / `_finishReload` 里用默认弹种覆盖整条弹链，玩家排好的特殊弹会消失。
- `reserve` 只统计默认弹种；有玻璃纤维弹但显示 0，导致无法换弹。
- 扣弹按弹种汇总后清空 queue，可能与实际剩余不一致。

**新行为**
- `inventory.js` 新增弹链 API：`normalizeLoaded / getLoadedGroups / isAmmoCompatible / listCompatibleAmmo / loadAmmoFromItem / unloadAmmo / countCompatibleAmmo / consumeCompatibleAmmo`。
- `loaded.queue` 是唯一真相源；`qty` 只做缓存；`loadedPreference` 记录首选弹种。
- `bagUI` 详情显示真实弹链分组（按顺序）、下一发、首选弹种；支持 `装 1 / 装满 / 取 1 / 全取 / 全部扣下`。
- 正常战局内改为“设为首选 + R 换弹”；靶场/仓库可直接整理弹链。
- 靶场无限弹药只补足队列，不覆盖已有顺序；优先补 `loadedPreference`。
- `reserve` 按兼容口径统计随身容器（不含仓库）。
- 旧存档 V1/V2 反序列化、`createItem`、`transferItem` 都调用 `normalizeLoaded` 修复弹链。

**文件**
- `inventory.js`
- `bagUI.js`
- `game.js`

**验证**
- 混合弹链显示顺序正确；取 1 不改变其余顺序。
- 5.56 武器装玻璃纤维弹后 `reserve` 非 0，换弹优先装它。
- 靶场射击后已排好的弹链顺序不被整体覆盖；特殊弹会按队列顺序逐发消耗，补弹从队尾加入。
- 背包满时扣弹整体回滚，不丢子弹。

### 2. 伤害/健康模型校准

**旧行为**
- 护具吸收硬编码等级表，与 `content.armor.red` 不一致。
- 头部壳+面罩双层叠加；腹部也吃插板。
- 未击穿统一 `remaining *= 0.25` 钝击。
- 护具耐久 `absorbed / 25`。
- 即时失血固定 `energy * 0.4`；低血容量 50% 才触发。
- 健康度只看组织，不看失血。

**新行为**
- 护具吸收以 `content.armor.red` 为单一来源。
- 分层钝击：插板 0.08、头盔壳 0.10、面罩 0.12、纤维 0.28；只有未击穿才乘。
- 头部只走一层；胸部先插板后纤维；腹部只走纤维。
- 耐久按 `absorbed / 40J` 消耗。
- 即时失血 = `energy * 0.08 * 部位血管密度 + 伤口等级 * 12`。
- 低血容量阈值 35%。
- `healthQuality = min(组织健康, 血液比例)`。
- `CombatSystem.applyArmor` 删除隐藏的全局 ×0.25。

**文件**
- `game.js`

**验证**
- Lv3 插板吃 5.56 不致命，护具耐久按 40J/点下降。
- 头部不再双重护具；腹部不吃插板。
- 受伤后 HUD 健康度随失血下降；35% 触发低血容量。
