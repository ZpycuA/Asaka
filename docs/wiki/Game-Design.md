# 第一部分 · 游戏设计总览

> 本页是“设计真相源”。任何数值以 `content.js` 与 `game.js` 常量为准；本页负责解释**为什么这样设计**、**数值之间是什么关系**、**哪些地方容易被改坏**。

---

## 1. 定位与设计原则

### 1.1 定位

- 极其硬核、纯物理仿真的 3D 撤离射击游戏，塔科夫 / 猎杀对决风格。
- 继承 Praze 世界观（见根目录 `Praze.md`），当前处于 **Asaka Straight Project（ASP）** 阶段：只做战斗，不做剧情。
- 核心体验：**在信息不全、身体会失血、护具会被打坏、弹药会打空的前提下，带着战利品活着撤离。**

### 1.2 第一原则

> **仿真优先于游戏性平衡。**

- 不为了“好玩”随意加入血条、魔法减伤、无限体力。
- 所有伤害最终都落回：动能（J）、穿透、护具吸收、钝击传导、组织损伤、失血、状态。
- 数值可以为了可玩性做**有记录的近似**，但不能出现双重语义、假数据、拍脑袋覆盖。

### 1.3 技术约束

- 纯 ES Modules + Three.js + 原生 DOM。
- 无 npm、无打包工具、无构建步骤。
- 移动端与 PC 同权：键位/按钮由 `ACTION_MAP` 单一真相源派生。
- 所有静态数据进 `content.js`；所有文案进 `locale.*.js`。

## 2. 核心循环

1. **配装**：仓库、市场、制式券、创造模式（靶场）准备武器/护具/弹药/投掷物。
2. **进入战区**：选择地图、角色、玩法预设；加载外置地图 JSON 或内置布局。
3. **搜索与交火**：搜刮容器/尸体、管理背包、用真实弹道与护具模型战斗。
4. **身体状态管理**：止血、骨折、失血、疼痛、燃烧、玻纤滞留、失明/震撼。
5. **撤离或死亡**：
   - 成功：结算战利品、奖励、任务。
   - 失败：掉落主/副/近战/护具/背包/胸挂，安全箱保留；进入战斗记录/死亡回放。
6. **回到仓库/市场**：卖战利品、补配装、再进。

## 3. 模式

| id | 名称 | 状态 | 特点 |
|---|---|---|---|
| `straight` | 硬核撤离 | 主力 | 只跑战斗；死亡有战斗记录与死亡回放；无剧情 |
| `asaka` | 主模式 | 已接大厅/序章 | 主大厅、计划树、唯一自动存档、3D 剧情 UI；正式地图后续扩展 |
| `training` | 靶场 | 独立 kind | 不写入正式玩法；无限子弹/技能无冷却/人偶/创造物品库 |

### 主大厅与计划树（v3.3.0）

主模式不再从 Straight 的“选地图/选角色”开始，而是进入正式主大厅：

- 左下菜单：开始游戏（建立主模式新存档）、继续游戏、计划树、Straight 模式、关于。
- 背景图为待接的 Default 图，目前只用 CSS 渐变占位；以后直接替换 `assets/lobby-bg.jpg` 并在 `index.html` 取消注释。
- 关于页：LA 引擎图标、本地游戏图标、Praze 世界观外链、制作者、GPL-3.0 / CC BY-NC 4.0 与 Three.js MIT。

计划树同时承担剧情轨迹与存档管理：

- 节点状态：已完成 / 当前 / 未抵达；金色树枝与深色背景。
- 自动存档只有一个，只有关键节点会写入；读档只能回到该关键节点，不能回到任意一句台词。
- 自动存档图标是缓慢旋转的三环结；序章结束写 `prologue_end`，读档会回滚该节点之后的选择。
- 数据源：`src/story/asaka-plan.js`（节点/分支）与 `src/asakaSave.js`（进度/autosave）。

### 剧情系统（v3.3.0）

- 剧情是“3D 场景中的 UI”，不是立绘 + 背景图：播放时世界暂停但继续渲染，UI 浮在场景上。
- 点击 / 空格 / 回车推进；支持选项、打字机、数字键选择。
- 演出期间隐藏 HUD、移动控件、暂停与设置，禁止存档与背包；章节结束后才允许写关键节点自动存档。
- 章节文件在 `src/story/`，只描述文本、说话人、下一节点、选项与 flag；逻辑在 `src/story.js`。
- 触发点来自地图 JSON 的 `storyTriggers`（`x/z/r/chapter/once`），玩家进入半径才播放；已读章节不重复。
- 当前序章约 20 个节点、两个选择支，选择写入 `prologue_trust` / `prologue_plan` 与凯特/玲娜好感度。

### 模式与地图关系

- 正常模式：地图来自 `menuState.map`（`factory` / `desert` / `lab`）。
- 训练场：固定 `mapId = 'training'`，不随菜单地图选择变化。
- 训练场不会触发撤离倒计时，不生成撤离点。

### 地图 JSON 字段

```json
{
  "id": "factory",
  "size": 200,
  "playerSpawn": { "x": 0, "z": 0, "angle": 0 },
  "obstacles": [
    { "x": 0, "z": 0, "w": 3, "d": 3, "yMin": 0, "yMax": 3, "type": "building" }
  ],
  "containers": [{ "x": 0, "z": 0 }],
  "extracts": [{ "x": 0, "z": 0 }],
  "enemySpawns": [
    { "x": 0, "z": 0, "spec": "nipsel_guard", "squad": "alpha", "patrolRadius": 12 }
  ],
  "storyTriggers": [
    { "x": 0, "z": 0, "r": 8, "chapter": "asaka.prologue", "once": true }
  ]
}
```

- `obstacles[].type` 决定颜色：`crate` / `step` / `platform` / `pillar` / `lowWall` / `building` / `roof`。
- `enemySpawns[].spec` 优先；缺省时按 `faction` 从敌人池抽。
- `storyTriggers[]` 只在主模式生效：玩家进入半径触发对应章节，`once` 默认 true。
- 布局加载失败：训练场使用**内置靶场布局**；普通地图退化为随机障碍。
- 相对路径按 `import.meta.url` 解析，避免页面 URL 尾斜杠问题。

| `5.56` | 5.56 | 4.0 | 940 | 1767 | 4 | — | 60 | L1 |
| `7.62` | 7.62 | 8.0 | 800 | 2560 | 7 | — | 80 | L2 |
| `.45acp` | .45acp | 14.9 | 290 | 626 | 2 | — | 25 | L0 |
| `train` | 60 | 0.60 | .45acp | 1 | — | 25 | L0 |
| `12ga` | 12ga | 3.5 | 410 | 294 | 0 | — | 40 | L0 |
| `dragon` | 12ga | 3.5 | 410 | 294 | 2 | 燃烧（等级 2） | 180 | L2 |
| `glassfiber` | 5.56 | 4.0 | 940 | 1767 | 0 | 玻纤滞留 | 420 | L4 |

| `12ga_slug` | 12ga | 28.0 | 450 | 2835 | 5 | 单颗重弹头 | 120 | L2 |

\* 枪口动能按 `0.5*m*v²` 计算；12ga 为**单颗弹丸**能量，实际霰弹枪一次 9 颗。
- **“冲压”列是 `impulse`，真实公式是 `basePen = ammo.pen + ammo.impulse`**（见 [Combat-And-Health](Combat-And-Health.md) §4.3）。所以 5.56 实际穿透是 3+1=4、7.62×39 是 5+2=7、7.62×54R 是 7+3=10、AP 钨芯是 7+2=9、`.45acp` 是 1+1=2。下表“pen”只是弹种字段本身：

| 弹药 | pen | impulse | 实际 basePen | 能打穿几级护具（diff≥0 才算不削弱） |
|---|---:|---:|---:|---|
| `9mm` | 0 | 0 | 0 | 连 Lv1 都吃力 |
| `.45acp` / `train` | 1 | 1 | 2 | Lv2 |
| `5.56` | 3 | 1 | 4 | Lv4 |
| `7.62` | 5 | 2 | 7 | Lv5 也基本无视 |
| `762x54` | 7 | 3 | 10 | 打穿一切常规护具 |
| `12ga` 鹿弹 / 龙息 / GF | 0 | 0 | 0 | 吃护具吃到饱 |
| `12ga_slug` | 4 | 1 | 5 | Lv5 |
| `ap556` | 7 | 2 | 9 | Lv5 |
| `12.7mm` | 10 | 4 | 14 | 打穿一切 |
| `p_laser` | 9 | 5 | 14 | 打穿一切 |

所以“AK 的 7.62 打不穿 5 级插板”是**对不上的**：真正吃核心原因是 `redMul` 只有 0.2（diff=3），护具仍然能吃掉大头；不是穿不了。

- 独头弹 `12ga_slug` 带 `pellets: 1`：`_fireWeapon` 用 `ammo.pellets || def.pellets || 1`，所以 sg12 装独头弹只发射 1 颗 28g 重弹头，不再一次喷 9 颗。

> GF 玻纤弹现在覆盖常见口径：`9mm_gf` / `glassfiber`（5.56 GF）/ `762_gf` / `45acp_gf` / `12ga_gf`，显示名统一为“口径 + GF 玻纤弹”。`dragon` 的规范显示名为“12 号龙息燃烧弹（Dragon’s Breath）”。

### 弹药兼容规则

- 武器 `ammoType` 与弹药 `caliber` 相等才可装填。
- `5.56` 武器可以装 `glassfiber`；`12ga` 武器可以装 `dragon`。
- 备用弹药统计按“兼容口径”，不是只统计默认弹种（旧版 bug）。

#### 外骨骼（「执政官」）
- 占 `vestFiber` 槽；`armorLv 6`、重 18.5kg、价值 68000、`rarity:'INC'`。
- 电池在 `subSlots.battery`（`battery.exo_cell_hi`，耐久=电量，300；约 15000J 抵消余量）。
- 能量抵消：每点电量抵消 50J，最多吸收 78% 伤害；对枪弹/破片/爆炸/钝击/头部都生效。电池耗尽或 EMP 损坏后外骨骼失效，不再提供 lv6 护甲。
- **头显可选**：`L` 或详情按钮戴上/取下。戴上才走 NIPsel 冷启动（黑屏 → NIPsel 标志 + TACTICAL EXOSKELETON → 蓝色扫描叠层），才标记敌人、启用挂载切换/自动火力；不戴不耗头显电。
- **喷气背包**：空中再按一次跳跃，向后喷气并获得类似猫跃的抬升，电池 -7。
- **6 个挂载硬点**：详情里拖枪装上；头显在线时 `4~9` 接管对应硬点，或由外骨骼自动火力自行瞄准射击。自动火力只操纵硬点上的枪，不替玩家扣手里的扳机。挂载枪计入负重。
- 冲刺 1.32× 并额外耗电（仅头显在线时）；不戴头显时系统“待机”，不消耗电池。声纹 85m 并显示敌我/威胁标签。
- **抗磁层**：`empShieldMax/empShield` 先扣抗磁耐久，未耗尽不会损坏；耗尽后才按概率结算 EMP 损坏。外骨骼纤维 240、电池 160，详情可查看百分比。
- **全身密封**：穿外骨骼时 `EntityStatus.immuneBurn = true`，火焰/龙息/温压点火都不会染上着火；脱掉后恢复正常。
- **激光/战术灯**：默认关闭，`Home`/`End` 或 HUD/移动端按钮开关；关闭不耗电、无光束。激光从枪口指向准星命中点，战术灯有实际光场与可见体积光。
- **没有插板槽**：插板不能装入外骨骼；旧存档里错误塞入的板会在启动时退回背包。
- 完全不可修补；只有电池可以更换。
- 不存在“队友版外骨骼”：玩家穿外骨骼时，队友只按常规 4 级复合护甲生成；外骨骼的丰富情报只以降级形式共享给队友。

### 8.4 重量与物品分类

- 所有护具/背包/胸挂都有 `weight`（kg）；武器/弹药/投掷物/贵重品/医疗也都有重量。
- HUD 显示 `当前重量 / 上限` 和 `正常 / 负重 / 超重`：
  - 正常：≤75% 上限；
  - 负重：75%~100%；
  - 超重：>100%。
- 负重上限：人类基准 34kg（军人战斗负重）；Prazer 按 `140·ln(A)` 硬拉力折算 `34 × (pull/80)^0.6`，A3 约 50kg、A4 约 58kg、A10 约 78kg。叶的 `carryBonus` 继续乘算。
- 体力：冲刺消耗随疲劳上升（1~2.2×）并乘负重系数；恢复速度随体力降低而变慢（0.55~1.45×）。Prazer 最大体力为 `110+2A`。
- 新增 `valuables`（贵重品/情报）与 `medical`（医疗）表，容器、市场、创造模式都会出现；物品详情显示分类、重量、电子属性与损坏状态。
- 负重硬上限：`carryLimit × 1.35`。超过后随身容器拒绝新物品（`Inventory.maxCarryWeight`），离开战局自动解除。
- 硬上限覆盖所有入口：世界容器（`c:loot`）、仓库（`c:stash`）、随身背包内部网格（`inner:`）、直接拖到装备槽、跨 Inventory 直接装备、以及插板安装。只有“已经携带的物品挪位置”不重复计重。
- HUD 超重时显示 `当前重量 / 软上限（硬上限 X）`；背包工具栏同样显示硬上限。

- **`HP` 列在当前实现里不直接等于“打多少 J 才死”。** `_spawnEnemy` 里 `enemy.hp = spec.hp × diffMul × (0.5 + 实时难度评分)`，主要用于 HUD 展示和血量比例；实际生死由 `EntityStatus` 的部位 J 值、血液量和伤口决定。体型倍率（`partScale` / `bossPartScale`）的读取路径在 `_spawnEnemy` 里**没有把 `spec.bossPartScale` 传给 `EntityStatus`**，也就是说 Boss 的部位 J 上限目前就是小兵那套 `60/800/600/400/500`（外加 `headHpMul` 只抬头部）。这跟“1400 HP 的雪乃和 100 HP 小兵同一套胸腔”的注释对不上，做难度评估/调平衡前必须先确认这是不是有意为之。
- 命中判定只在头/胸/腹/腿之间落点（见 [Combat-And-Health](Combat-And-Health.md) §3），手臂部位在命中树里基本不参与，`larm` 只在特殊逻辑里用到。
- AI 属性：`aggression` / `composure` / `perception` / `opportunism` / `keepDistance` / `meleeBias` / `switchBias` / `grenade`（0 表示不会扔投掷物）。
- `acc`（命中）不是直接查表命中率，而是折成一个散布倍率：`accMul = clamp(1.35 - acc*0.9, 0.45, 1.05)`。所以 0.50 的执勤和 0.94 的银行狙击手差 2.33 倍散布，而不是“50% vs 94% 命中”。
- 感知半径：`maxDist = min(140, max(18 + perception*28, 武器射程*0.8))`，视野锥 `π/2 + perception*π/3`；被闪盲期间直接找不到目标。
- 反应：进入战斗时 `reactionTimer = max(0.05, 1.5 - composure*1.2) + 0~0.3s`。镇定 0.99 的 Moments 反应约 0.3s，镇定 0.28 的执勤要 1.2s+。
- `gear.armor` 只决定战斗护具；掉落物沿用同一套装备。
- AI 属性：`aggression` / `composure` / `perception` / `opportunism` / `keepDistance` / `meleeBias` / `switchBias` / `grenade`（0 表示不会扔投掷物）。
- AI 移动手感：通用间距/反应/点射/侧移/包抄参数在 `content.js → aiRules.default`；交火时保持“双方碰撞半径 + spacingMargin”，贴脸先退出碰撞体，舒适距离内持续侧移，推进时按小队包抄，换弹/重伤找掩体。
- 同阵营默认不主动互相开战；玩家与所有武装阵营敌对。
- 投掷物：`gear.nades` 决定基础携带；`special.nades` 是特种档覆盖。强 AI（elite / mobile / bank_guard / leader 等）在 7~34m、有库存、冷却结束且队友不在爆区时进入 `nade` 状态，0.7~1.2s 前摇后投出。AI 的投掷物是真实物品，扔一枚少一枚，尸体可搜，搜刮时最多补充 2 枚。
- 战术机动人员 `special`：72% 概率抽到特种配装，包括双持 sg12 + smg45、龙息弹（12ga）/ 玻纤弹（.45acp）、Lv4/4/4/5 护甲、破片/闪光/震撼；未抽中时使用基础 Lv3 护甲与 smg45/sg12。
- **地图 Boss**：`factory → boss_nipsel_leader`、`desert → boss_krona`、`lab → boss_yukino`。Boss 取离玩家出生点最远的既有防区生成，不刷在出生点脸上，也不再走 `enemyCount` 随机池。

### 10.1 友方 AI 小队（可选）

- 共享标记使用 `world._markEntity(target, duration, by, faction)` + `markedFaction`；敌方无人机/侦察技能以后用同一入口即可让敌方 AI 共享情报。
- 训练场不生成队友；关闭开关后下一局恢复单人。
- 队友血量 <55% 或出血 ≥2 级会主动撤退到掩体后，>68% 且无出血才回到进攻；撤退到 16m 外会停下自我急救。
- 敌我 AI 均有 `selfaid` 状态：无视线（或已退到安全距离）且健康 <68 / 有出血时，停步蹲下 2.6~3.6s，按伤情选绷带/血浆/手术包。医疗兵也会先处理自己的伤。
- 同阵营倒地者（含玩家）会被 **24m 内**队友优先救援：靠近 2.3m、持续 3.2s 后消耗药品扶起；寻路会绕墙而不是直线顶墙。
- AI 移动由 2m 网格 A* 驱动：调查、搜刮、互救、逃跑、巡逻、队友跟随/探索/建议/撤退都会绕开墙体；视线直达时仍走直线。
- 队友有自主计划 `search/fight/extract`：玩家进入撤离区、撤离开始或剩余 <75s 时会优先向撤离点靠拢，到点后就地防守；计划变化会在队内频道报点。
- 小地图共享队友位置：存活绿点、倒地红点 + 白叉。
- 玩家靠近队友 4.5m 可查看伤情并用自己的医疗用品救治；手术包/血浆能救起倒地队友。
- 队内建议：`P` 前进 / `O` 撤退，按准星落点生成 3D 标记；无人机操控中同样可用（取无人机准星落点，HUD 也有前进点/撤退点按钮）。AI 按自身状态自行决定是否执行，不是硬命令。
- 敌我 AI 都会使用投掷物（强 AI 7~34m、有实物库存、0.7~1.2s 前摇）；队友带 2 枚破片，出手时会报“吃颗手雷”，且不会朝玩家脚边的目标扔雷。
- 敌方 AI 同样拥有 `aid` 状态与基础药品（绷带；精锐/队长/机动/警卫额外手术包），会互相救起。
- **队友随机**：从凯特/玲娜/布雯中排除玩家本人后随机抽 2 名；每局重新洗牌。
- **近战与尾击**：Prazer 拳/近战伤害按 `140·ln(A)` 力量放大；`M` 尾击（移动端按钮）2.8m、约 2.2 倍拳击能量、24 体力、1.1s 冷却。人类按 M 会提示没有尾巴。
- **自动跨越/攀爬**：只有矮墙/箱子/台阶/平台 `climbable`；低矮障碍移动自动越，超过 1m 需跳跃；Prazer 翻越高度约 2.1~2.3m，建筑/屋顶/高墙不可攀爬。低顶屋内跳跃前会检查头顶净空并限制初速。
- **背叛**：玩家连续两次（6s 内）枪/近战命中队友，或单次造成 >60% 健康/击倒，队友立即脱离队伍、拉开枪线并把玩家当敌人；第一次非致命命中只警告。AI 开枪前也会检查枪线，队友挡线时停火。

### 10.2 Assee 异常容器与 Moments『初等』

- **降临**：非训练场每局按 `content.asce.default.chance`（默认 0.6，再乘难度系数）概率，在开局约 14s 后于离玩家 30m 以外的可达防区生成；调度已移到“地图自带容器”早退之前，因此正式战局不会再被地图 JSON 的容器列表截断。设置里可开启“下一局必出 Assee 容器”调试。
- **容器外形**：悬浮的双层不规则多面体结晶 + 内部脉动核心 + 轨道碎片 + 三层地面法阵，不再复用物资箱模型；有独立编号 `ASCE-XXXXXX`，只含一件 INC 级 `asce_core`。核心是“裸露”的，任何角色都能直接拾取。
- **P 空间波动**：容器和撕裂口都会周期性发出可见扩张环。半径内的 Prazer（玩家和 AI）获得 `pspace_echo`（移速/操控/近战力量/体力恢复上升）与 `nausea`（视野与操控下降），并收到字幕 + 浏览器语音警告。人类看不到增益，但能看到波动环。
- **锚定与带离**：拾取核心后全图暴露持有者位置（每 8s 向敌对 AI 广播最后已知坐标）。需要把核心护送到独立的**锚定站**，在站内连续锚定 `anchorTime`（默认 90s）；锚定期间离开站会缓慢回退进度。锚定完成后 P 空间失稳计时停止，再完成撤离倒计时才算完整到手，奖励 `content.asce.default.reward`（默认 50000 cp）。未锚定直接撤离只能拿 `rawRewardMul`（默认 15%），核心会在撤离舱内崩解、不保留物品；已锚定核心则保留为完整电子资产。
- **破坏**：若 180s 内既没有完成锚定、也没有带离，P 空间在**独立裂口坐标**（离容器 45~75m）被撕开：黑色狭长裂缝 + 三层反向环 + 碎片 + 电弧 + 点光 + 巨响。Moments『初等』从裂口逐个出场，再向容器推进，不再贴脸刷在容器脚下。
- **Moments 编制**：队长、盾兵、破门/爆破手、突击队员、携带员、侦查/医疗兵；对应 `moment_leader/moment_shield/moment_breacher/moment_assault/moment_carrier/moment_scout_medic`。属性 `partScale 13~19`、`damageResist 0.06~0.14`、`armorDurMul 8~13`、`headHpMul 10~13`，配备 180~240kg 的专属机枪/空间激光器与 12000J 肘击；玩家正常无法携行。
- **警告机制**：Moments 初始为被动，先字幕 + 语音警告“放下武器、离开容器”；玩家持械进入 10m 停留 3s、6m 内、开镜贴近、在 48m 内开火，或在 45m 内赖过 15s 警告时限后，全队转入战斗。携带核心会额外缩短挑衅时限（6s）。
- **Cat Cat Catch**：Moments 的狩猎本能状态。触发源包括：听到敌对声音；附近有 Prazer；Prazer 使用技能；P 空间波动（容器状态改变、锚定完成、核心被拿走/丢弃）。进入后全队获得移速、侵略性、射击稳定性加成，并直接锁定目标最后位置；若目标是 Prazer，会收到一条“位置暴露：被遡踪”的感知级警告，以及全队语音 `Cat Cat Catch.`。失去视野时也会自动进入此状态，而不是站在原地看着玩家消失。
- **P 空间补给**：缺弹或重伤的 Moments 会在身边撕开一个紫色小型补给口，约 2.2s 后取回弹药、药品与破片；玩家在 12m 内时不会当面慢悠悠补给。
- **小队战术**：队长/侦察持续共享玩家最后已知位置；盾兵占据“队长—玩家”连线上的前沿盾位；携带员在容器未被拿走时直取容器；全队统一压上但保留职责间距。侦查/医疗兵会放出实体侦察无人机：每 5s 标记玩家并共享位置、朝 24m 内玩家投掷破片，本身可被子弹击落；凯特的直觉能额外提示无人机方位。
- **携带员真正夺取**：携带员到达晶体或地面核心后会把核心拿走（`carriedByMoment`），随后向裂口撤退；进入裂口 4m 内事件判定为 Moments 得手。击杀携带员会把核心重新掉在尸体旁，玩家可以抢回，事件继续。
- **容器崩塌**：核心被拿走（包括丢下装着核心的背包）后，原地的晶体模型立即崩塌消失，只保留锚定站与事件 HUD；不会出现“核心在身上、原地还亮着晶体”的鬼影。
- **尸体 Assee 核心**：任何 Prazer（含敌方常规兵、Boss、Moments、友方 Kate/Lingna）死亡后，尸体搜刮界面会出现独立的 **Praze 栏**：3D 濒碎核心预览、原主、核心等级 `A` 与 `L1~L5/INC` 评级。只有当前角色是 Prazer 且 `aseLevel > 核心A` 才能把核心**提取成一件物品**（`praze_core`，物品等级就是 `L1~L5/INC`）；人类点击会触发全屏混沌红字 `Kaprz,haispelo`。提取后的核心进入背包/胸挂，打开物品详情可再次选择“吸收核心”：消耗物品，提升基础耦合等级与耦合上限，同时引发 P 空间波动并挂上 `pspace_echo + nausea`。核心等级超过设定过强阈值 `10^20` 时为 INC，普通 Prazer 无法提取/吸收。
- **击退/失衡**：所有近战重击与爆炸按实际动能计算位移；≥3000J 触发失衡，玩家短暂失去移动/开火，AI 短暂硬直；地图边界会夹取，不会被打飞出几千米。

> ⚠ 上面这个“玩法预设”只是**一键配置项**，不是菜单里那个“实时难度 0~100”的来源。菜单里的 `<div id="difficulty-display">` 读的是 `engine.js → ProfileSystem.assess()`：
> `score = clamp(0.5 + (开启的仿真项权重和/权重总和 - 开启的辅助项权重和/权重总和) × 0.4, 0.05, 0.95)`，
> 再按 `<0.20 休闲 / <0.40 普通 / <0.60 战术 / <0.80 硬核 / ≥0.80 拟真` 分档，奖励倍率 0.5 / 0.75 / 1.0 / 1.5 / 2.0。
> **同一个评分还被拿去改敌人强度**：`_spawnEnemy` 里 `profileMul = 0.5 + score`（例如硬核 0.75 → ×1.25 血量），`_spawnEnemies` 另有一个 `diffMul`，但菜单里目前**没有**难度选择器，`menuState.diff` 恒为 `'normal'`（×1）。
> 也就是说：你把 HUD/小地图/技能换成“仿真实时难度”时，敌人的血量也会跟着变高；想让敌人变弱只能改玩法预设，改不了 `diffId`。

**“哪一档都能玩”不是设计承诺**：仓库/制式券/角色技能是真实存在的差距，下面 §16 给了一份按玩家阶层的难度评估。

## 15. 死亡回放设计

- 不做“从出生点重跑 AI”的模拟（随机性会分叉）。
- 10Hz 全实体快照：玩家/敌人的位置、朝向、生死、HP、血液、护具、武器、弹药、瞄准点、`status.effects`。

  - 清空死亡蒙版/眼皮/技能滤镜。
  - 敌人状态用头顶图标 + 身体发光表示。
  - 击杀者 HUD：HP/护具/武器/弹药/状态栏。
  - 无击杀者时 HUD 显示“死亡回放 / 无击杀者”，不残留濒死面板。

### 16.1 “失真点”台账（改动前先读）

下面每一条都是**代码与文档/直觉不一致**的地方。不是 bug 报告，是提醒：写平衡评估、改数值之前先把它们对上，否则会拿错参照物。

| # | 位置 | 现状 | 文档/直觉怎么说 |
|---|---|---|---|
| 1 | `_spawnEnemy` → `new EntityStatus(spec, isPrazer)` | 只传 `spec`，读 `entity.partScale` / `entity.boss` / `entity.bossPartScale`；但 `spec.bossPartScale` 不会被读，`isPrazer` 只从 `spec.prazer` 推 | “850 HP / 1400 HP 的 Boss 部位耐久按 250HP≈1× 放大” |
